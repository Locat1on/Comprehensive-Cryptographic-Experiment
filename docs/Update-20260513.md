# 更新记录 - 2026年5月13日

## 1. 大文件局域网传输功能升级 (中继模式)
实现了基于局域网的大文件安全传输方案，支持浏览器分片上传。

- **后端增强**:
    - `SecureFileTransfer` 类重构为中继模式，移除服务端加解密逻辑。
    - 实现了传输会话管理、分片存储和公钥转发功能。
    - 新增 API 路由：`/file/init`, `/file/join`, `/file/status`, `/file/chunk`, `/file/pull`。
- **构建验证**: 成功运行 `build.ps1` 编译后端 `server.exe`。

## 2. 端到端 (E2E) 加密方案实现
将加密逻辑从服务端完全移至客户端，确保服务端无法获知原始文件内容。

- **前端 Crypto 模块**:
    - 新建 `frontend/js/crypto.js`，实现与 C++ 端互操作的 DH 密钥交换和 XOR 流密码算法。
    - 使用 `BigInt` 实现高性能模幂运算。
    - 集成 Web Crypto API (SubtleCrypto) 计算 SHA-1 哈希生成密钥流。
- **安全特性**:
    - **前向保密**: 每次传输生成独立的临时 DH 密钥对。
    - **密钥指纹**: UI 提供 16 位密钥指纹对比，防止中间人攻击。
    - **端到端加密**: 密文分片由浏览器加密后上传，由接收方浏览器下载后解密。

## 3. UI/UX 体验优化
针对用户反馈的界面对比度问题进行了深度优化。

- **文字清晰度提升**:

    - 引入了自动轮询机制，实时同步传输状态和进度。
